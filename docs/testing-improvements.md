# Effect Testing Improvements Tracker

Working tracker for the Effect test audit (2026-09-03). Each task is owned by one
subagent run so parallel tasks never touch the same files. Update `Status` and
`Notes` when a task finishes. Do not start a task whose files overlap an
in-progress task.

Verification commands:

```sh
rtk nub exec vitest run <path/to/test-file>   # single file
rtk nub exec vitest run                       # full suite (expect slow)
```

Conventions for every task:

- Use `nub` (never npm/pnpm). Prefix shell commands with `rtk`.
- Effect v4 (rc.111): `Effect.gen`, `Effect.fn`, `Schema.TaggedError`.
- Prefer real PGlite/RustFS over mocking; assert `_tag` + fields, not message substrings.
- Never leave `void value` discards or `.catch(() => dummy)` in tests.
